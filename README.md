## NZ Health & Wealth · 在新西兰，好好生活

面向中文读者的新西兰健康与财富指南。从 **The Health Hub** 和 **Smart Money** 的本地对话出发，把就医、用药、KiwiSaver、家庭财务等问题整理成可以查阅和行动的内容。

每条保留适用边界与查证入口；节目引用附单集、日期和真实字幕时段，政策、费用与资格另核对官方资料。当前 v1.1.0 包含 **111 条场景指南**（Health 54、Wealth 57），109 条节目引用来自 84 集的选定片段，并公开节目目录与审阅状态。本轮从此前未采用的 24 集新增 25 条，未逐期完整蒸馏全库。
